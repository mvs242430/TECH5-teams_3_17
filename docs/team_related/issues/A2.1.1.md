# Issue A2.1.1 — Compare: solutions with different students

`team-a` · A2 · Week 3 · S · Needs: A2.1, B1.3

**What and why:** `compare_two_solutions` refuses two solutions that do not contain the same students, and raises `ValueError`. The `/compare` route does not catch it, so the user gets an error page instead of a message. This is easy to reach: loading any scenario deletes all students, the database cascade then deletes the assignments of every older solution, but those emptied solutions stay in the Compare dropdown. Comparing one with a new solution crashes, and comparing two emptied ones shows a blank result.

Comparing different assignments of the same students is the core feature and must keep working. Solutions with different students stay non-comparable: the engine's refusal is correct, only the page's handling is missing.

**Files:** `app/visualization/routes.py` (`compare_solutions`), `app/persistence/repositories.py` (new read method on `RunRepository`), `app/contract/contract.py` and `app/engine/solvers.py` (docstrings only: document the `ValueError`), `tests/test_visualization_component.py` (new tests only; do not modify existing tests), `docs/team_related/issues/A2.1.1.md`, `docs/team_related/issues_solutions/A2.1.1_solution.md`.

**What to build:**
- In `RunRepository`, add a read method that returns the IDs of solutions that still have at least one assignment. `list_runs` loads metadata only, so `sol.assignments` is always empty there and cannot be used as the filter.
- In `compare_solutions`:
  1. Show only solutions that still have assignments in both dropdowns.
  2. If either selected solution has no assignments (possible through an old link), show a red message and redirect to `/compare`. This check must run before the engine, because two empty solutions pass the engine's check.
  3. If the engine raises `ValueError`, show a red message and redirect to `/compare`.
- Add the `ValueError` to the `Raises:` section of `AssignmentEngineContract.compare_solutions` and `AssignmentEngine.compare_solutions`. Do not move the check out of Component B, and do not import Flask there.

**Done when:** ☐ a 10-student run against an 11-student run gives a red message, never an error page ☐ an old run against a new run after a scenario load gives a red message ☐ two emptied solutions give a red message, not a blank result ☐ emptied solutions are not in the dropdown ☐ two runs of the same cohort still compare normally ☐ new tests pass and all existing tests remain untouched and passing.
