# Issue A1.2 — Projects: create, edit, delete (with required skills)

`team-a` · A1 · Week 1–2 · L · Needs: A1.1

**What and why:** A project has a title, min and max seats, and a list of required skills with a level 1–5, each either "must have" (mandatory) or "nice to have". The page exists but saving crashes. The edit page also shows blank requirements instead of the saved ones.

**Files:** `routes.py` (`create_project`, `update_project`, `delete_project`), `templates/project_form.html`, `templates/projects.html`, `tests/test_visualization_component.py` (`test_projects_crud_workflow`).

**What to build:**
- The form sends: `id`, `title`, `description`, `min_capacity`, `max_capacity`, and for every skill `req_level_<skillid>` (0 = not required) and `req_mand_<skillid>` (ticked = mandatory).
- Build a project with one requirement for every skill whose level is above 0. Save it. Same for edit; delete removes it.
- In edit mode, pre-fill levels and checkboxes with the saved values.
- In `projects.html`, show seats and the required skills of each project.

**How to solve with the AI:** First ask it to read `ProjectRepository`, `models.Project`, `models.ProjectRequirement`. Then implement create, test it, then edit, then delete — three prompts, not one.

**Prompt:** "Read app/domain/models.py (Project, ProjectRequirement), `ProjectRepository` in repositories.py, and the form in project_form.html. Implement `create_project` in routes.py: parse the fields described in the issue, build a models.Project with requirements, save with ProjectRepository().save, flash success, redirect to the project list. Admin only. Show errors (red flash) for empty id/title or min>max. Do this first, then I'll ask for update and delete."

(second prompt) "Now implement `update_project` and `delete_project`, and make project_form.html pre-fill `req_level_*` and `req_mand_*` from `project.requirements` when editing."
