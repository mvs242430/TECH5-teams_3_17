# Issue B1.1 — Skill-fit score and Gini

`team-b` · B1 · Week 1 · M

**What and why:** *Skill fit* answers: how well does this student's skill level match what the project needs (0 to 1)? *Gini* measures how unequal the outcomes are (0 = everyone equal).

**Files:** `app/engine/metrics.py` (`calculate_assignment_skill_fit`, `calculate_gini`), `tests/test_metrics.py` (`test_skill_fit_calculation`, `test_gini_calculation`).

**Rules:**
- For each requirement: `min(student level / required level, 1.0)`. Score = average over all requirements. Example in the test: Python 3 vs 3 → 1.0, SQL 1 vs 2 → 0.5, average 0.75, unmet = `["sql"]`.
- Student with no skill counts as level 0. Project with no requirements → score 1.0, nothing unmet. Never divide by zero.
- Gini: 0.0 for an empty list, all-equal values, or all zeros; always between 0 and 1; negative values → clear error.

**How to solve:** Ask the AI to implement, then ask it to add extra tests: empty list, single value, zero-skill student, project without requirements. Remove the two xfail markers.

**Prompt:** "Implement `calculate_assignment_skill_fit` and `calculate_gini` in app/engine/metrics.py following the rules in the issue. Remove the xfail decorators from the two matching tests in tests/test_metrics.py and add tests for empty list, single value, zero skills, and no requirements. Edit only those two files. Run pytest."
