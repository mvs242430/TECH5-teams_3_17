# TECH5 Issues (GitHub-ready)

One file per issue. Copy the file content into a new GitHub issue (title = first line). Read [`../onboarding_for_students.md`](../onboarding_for_students.md) first.

How to read an issue: **Labels · Owner · Week · Size** (S ≤ 1 h, M ≤ half day, L ≤ 1 day) · **Needs first**. Each has *What and why*, *Files*, *How to solve with the AI*, *Prompt to paste*, *Done when*.

**Prompt rule used in every issue:** "Only edit the files listed. Do not delete or weaken any test. Run `python -m pytest -q` at the end and show me the result."
