# Issue B2.2 — The three strategies

`team-b` · B2 · Week 2 · L · Needs: B2.1

**What and why:** Three goals, three classes solved in Pyomo with the HiGHS solver (`appsi_highs`): **PreferenceOrientedSolver** (as many top choices as possible; unranked projects get a heavy penalty), **SkillFitOrientedSolver** (best total skill fit; uses `calculate_assignment_skill_fit`), **BalancedTradeoffSolver** (a mix, weights adjustable, default 50/50).

**Files:** `app/engine/strategies.py`.

**Rules:** names must be `PREFERENCE`, `SKILL_FIT`, `BALANCED` (the dashboard dropdown sends exactly these). `solve` returns `(status, assignments, objective_value, diagnostics)`. When no solution exists, return status `"INFEASIBLE"` — never crash.

**Prompt:** "In app/engine/strategies.py implement three subclasses of `AssignmentStrategy` named PreferenceOrientedSolver (name 'PREFERENCE'), SkillFitOrientedSolver ('SKILL_FIT'), BalancedTradeoffSolver ('BALANCED'), using the Pyomo `_build_base_model` helper and solving with HiGHS (`pyo.SolverFactory('appsi_highs')`). Implement `calculate_cost_or_utility` and `solve`. Fill each returned `models.Assignment` with preference_rank, skill_fit_score and unmet_requirements. Return status 'INFEASIBLE' instead of raising when HiGHS finds no feasible/optimal solution. Add one test per strategy on the standard scenario in tests/test_solvers.py."

**Done when:** ☐ each strategy gives a valid assignment on the Standard scenario ☐ tests pass.
