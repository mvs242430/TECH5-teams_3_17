# Issue A2.2.2 — Recommendations Top Summary Strip: Cards Only Without View Link

`team-a` · A2 · Week 3 · XS · Needs: A2.2

**What and why:** On `/recommendations/<run_id>` (**Transparent Decision Recommendations**), the top at-a-glance `.kpi-grid` summary strip wrapped each `.kpi-card` in `<a href="#rec-{{ loop.index }}">` while nesting a second `<a href="/solutions/...">View solution →</a>` link inside `<span class="kpi-sub">`. Because HTML5 forbids interactive `<a>` descendants inside an outer `<a>` element, browsers auto-closed each `.kpi-card` anchor before the inner link and ejected three standalone `View solution →` links directly into `.kpi-grid` between and beneath the cards. Moreover, each detailed recommendation card immediately below (`#rec-1`, `#rec-2`, `#rec-3`) already provides a dedicated **View Solution #N →** button. Removing `View solution →` from the top summary strip leaves only the three clean priority-focus cards at the top and restores valid HTML5 grid structure.

**Files:** `app/visualization/templates/recommendations.html`, `tests/test_visualization_component.py` (new A2.2.2 test only; zero existing tests modified), `docs/team_related/issues/A2.2.2.md`, `docs/team_related/issues_solutions/A2.2.2_solution.md`.

**What to build:**

- Preserve all per-recommendation detail card buttons (**View Solution #N →** and **Compare vs Alt #M**) in the detailed Evidence vs. Advice cards below.
