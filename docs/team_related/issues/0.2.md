# Issue 0.2 — Create the project board, labels, and PR template

`setup` `docs` · A1 · Week 1 · S

**What and why:** Gives the team one place to see who does what, and a checklist every PR must fill in.

**Files (new):** `.github/PULL_REQUEST_TEMPLATE.md`, `.github/ISSUE_TEMPLATE/task.md`.

**How to solve:** On GitHub: create labels (`team-a`, `team-b`, `shared`, `docs`, `week-1`, `week-2`, `week-3`, `blocked`), 3 milestones (Week 1/2/3), a board with 5 columns, and switch on "require a pull request before merging" for `main`. Ask the AI to write the two template files.

**Prompt:** "Create `.github/PULL_REQUEST_TEMPLATE.md` with sections: What changed (plain words), How I tested it (tests + page click-through), Screenshot, Linked issue ('Closes #'), AI use (what the AI did and what I corrected). Also create `.github/ISSUE_TEMPLATE/task.md` with: What and why, Files, Done when. Only create those two files."

**Done when:** ☐ a test PR shows the template ☐ pushing straight to `main` is blocked.
