## Issue 0.2 — Project Board, Labels and PR Template

### 1. Pattern & Rationale
GitHub reads files in `.github/` automatically:
- `.github/PULL_REQUEST_TEMPLATE.md` pre-fills the description of every new pull request, so every PR states what changed, how it was tested, which issue it closes and how the AI was used (needed for the Git evidence, X6, and the team reflection, D9).
- `.github/ISSUE_TEMPLATE/task.md` appears as a "Task" option under *New issue* and follows the same structure as the files in `docs/team_related/issues/`.

The board, labels, milestones and branch protection are **settings on GitHub**, not files, so they are done in the browser (section 3).
