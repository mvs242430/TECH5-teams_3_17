# Issue B3.2 Solution — Update Skeleton Tests Expecting `NotImplementedError`

## 1. Architectural Pattern Applied & Rationale
- **Pattern:** **Progressive Contract & Integration Test Activation**.
- **Rationale:** In the starter carcass, baseline tests asserted that `AssignmentEngine.__init__` had an empty `strategies` dictionary and that `AssignmentEngine.execute_run` raised `NotImplementedError`. Once `B3.1` implemented the real engine orchestration, those tests needed to verify the real contract behavior (3 registered strategies, completed runs, persisted solutions, and live `/compare` rendering without a `NotImplementedError` fallback).

## 2. High-Level Logic & Data Flow Walkthrough
1. **`tests/test_solvers.py`:**
   - Updated `test_assignment_engine_initialization` to assert `set(engine.strategies.keys()) == {"PREFERENCE", "SKILL_FIT", "BALANCED"}`.
   - Updated `test_assignment_engine_raises_not_implemented` to verify that `engine.execute_run(request)` returns a `COMPLETED` run with at least one solution.
   - Removed `@pytest.mark.xfail` from `test_distinct_alternatives_generation`.
2. **`tests/test_contract_and_engine.py`:**
   - Replaced `with pytest.raises(NotImplementedError): engine.execute_run(request)` in `test_contract_execute_and_retrieval` with assertions verifying `real_run.status == "COMPLETED"`, `len(real_run.solutions) >= 1`, and `engine.get_run(real_run.id) is not None`.
3. **`tests/test_component_integration.py`:**
   - Removed the `try ... except NotImplementedError:` wrapper around `client.get(f"/compare?sol1={sol1_id}&sol2={sol2_id}")` in `test_full_lifecycle_integration` so the integration test strictly requires the `/compare` endpoint to succeed.

## 5. Pedagogical Checkpoint — Check Your Understanding
1. **Why did `B3.2` have to be implemented on the same branch as `B3.1`?**
   - Because `test_assignment_engine_initialization` and `test_contract_execute_and_retrieval` explicitly asserted the unimplemented skeleton behavior (`len(engine.strategies) == 0` and `pytest.raises(NotImplementedError)`). Implementing `B3.1` immediately invalidates those skeleton assertions.
